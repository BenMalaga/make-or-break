PowerShell from the ground up. It runs on Windows, macOS, and Linux, and it is the
automation language for Windows administration, the cloud, and DevOps. The Build
tab has a browser practice PowerShell, so every cmdlet and pipeline in these
lessons can be run and changed on the spot.
