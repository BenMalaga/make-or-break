Someone dumped a flag straight to hex and forgot to convert it back.

Hex (base 16) is one of the most common ways to write raw bytes as text. Each
byte is shown as exactly two hex digits, so `4d` is one byte with value 0x4d,
which equals 77 in decimal, which is the ASCII code for the capital letter `M`.

Here is the hex dump:

```
4d4f427b6865785f69735f6a7573745f6261736531367d
```

Split it into pairs of hex digits, turn each pair into a byte, then read those
bytes as ASCII text. Do that across the whole string and you will recover the
flag.

Run your code, read the decoded text, and submit the flag exactly as it appears,
including the `MOB{ }` wrapper.
