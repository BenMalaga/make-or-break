A single-byte XOR cipher takes each byte of the message and combines it with the
same secret key byte using XOR. It looks scrambled, but it offers almost no
security: the key is just one byte, so there are only 256 possibilities. You can
try them all in a fraction of a second.

Here is the ciphertext as a hex string:

```
171518212235280535343f0538232e3f05313f2327
```

Decode the hex into raw bytes, then for each candidate key from 0 to 255, XOR
every byte with that key. The right key gives readable plaintext in the form
`MOB{...}`. Recognize it by the `MOB{` prefix, then submit the flag exactly as
it reads, braces included.
