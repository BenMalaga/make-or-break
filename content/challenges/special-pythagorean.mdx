A Pythagorean triplet is three positive integers a < b < c for which

```
a*a + b*b == c*c
```

For example, 3*3 + 4*4 == 5*5.

There is exactly one Pythagorean triplet whose three numbers add up to 1000:

```
a + b + c == 1000
```

Find that triplet and submit the **product** a*b*c.

You do not need three nested loops. Choose a and b, and the third number is
pinned down by the sum: c = 1000 - a - b. Loop a from 1 upward, loop b above a,
compute c, and keep the one case where c > b and a*a + b*b == c*c holds.
