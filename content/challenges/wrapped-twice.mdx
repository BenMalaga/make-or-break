Encodings stack. This flag was wrapped twice: the original text was first passed
through ROT13, and that result was then base64-encoded. What you see below is the
final, outer base64 layer.

```
WkJPe3lubHJlZl9jcnJ5X2Jzc30=
```

To recover the flag, peel the layers in reverse order:

1. Base64-decode the string above. That gives you the ROT13 layer, which looks
   like scrambled letters wrapped in braces.
2. Apply ROT13 to that text. ROT13 is its own inverse, so applying it once
   returns the original. Digits, braces, and underscores stay put.

Run the starter code, or do it any way you like, then submit the recovered flag
in the form `MOB{...}` exactly as it reads.
