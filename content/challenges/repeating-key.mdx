A Vigenere cipher extends the Caesar idea. Instead of one fixed shift, it uses a
repeating keyword: the first letter of the message is shifted by the first letter
of the key, the second by the second, and so on, wrapping back to the start of the
key when it runs out. That repetition is exactly the weakness the cipher is named
for here.

The flag below was Vigenere-encrypted with the keyword `MAKE`. Only the letters
were shifted. The braces and underscores passed through unchanged, and they do not
consume a key letter, so the key advances only when it lands on an actual letter.

```
YOL{zugorqro_vqpoefs_sxeevj}
```

To decrypt, walk the ciphertext left to right. For each letter, take the next key
letter in the cycle `M`, `A`, `K`, `E`, convert it to a shift of 12, 0, 10, 4, and
subtract that shift from the ciphertext letter (mod 26), keeping upper and lower
case as they are. Copy every non-letter straight across without advancing the key.
