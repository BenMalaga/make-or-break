Base64 gets mistaken for encryption all the time. It is not. It is an
**encoding**: a reversible way to carry bytes through a text-only channel, with
no key and no secret. Anyone can decode it.

Here is a base64 string:

```
TU9Ce2Jhc2U2NF9pc19ub3RfZW5jcnlwdGlvbn0=
```

Decode it back to plain text and you will find a flag in the form
`MOB{...}`. Run the starter code to do it, or decode it any way you like, then
submit the flag exactly as it reads.
