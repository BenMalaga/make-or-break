Computers do not store letters. They store numbers, and binary is just those
numbers written in base 2, using only the digits 0 and 1. A single character of
text fits in one byte, which is 8 binary digits.

Below is a flag, one character per group, each character written as 8 bits:

```
01001101 01001111 01000010 01111011 01100010 01101001 01101110 01100001 01110010 01111001 01011111 01101001 01110011 01011111 01100010 01100001 01110011 01100101 01011111 01110100 01110111 01101111 01111101
```

There are 23 groups. Read each 8-bit group as a base-2 number, which gives you a
character code, then turn that code back into its character. Join the characters
in order and you get a flag in the form `MOB{...}`. Run the starter code, read
the result, and submit the flag exactly as it reads.
