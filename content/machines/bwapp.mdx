## About this target

bWAPP, the buggy Web Application, is a PHP and MySQL app built by Malik Mesellem
to be broken on purpose. It packs more than one hundred web vulnerabilities
behind a single login, from SQL injection to command execution to file upload.
Like DVWA it has a security level selector, so you can dial a bug from low to
high and watch the filters change the attack. Start on low, learn the raw bug,
then climb.

Your two objectives here: **pull credentials out of the database through SQL
injection** (user), then **make the server run a command you supply** (root).

<Callout type="security" title="Authorized target only">
You are running this container on your own machine. That is the only reason it
is legal to attack it. Never point these techniques at an application you do not
own or have written permission to test.
</Callout>

<Callout type="info" title="How flags work on Phase A machines">
Docker and bring-your-own-VM boxes use proof tokens revealed through the hints
once you have genuinely completed the objective. Capture a flag by doing the
work, then submitting the token. Phase B hosted machines will issue real
per-instance flags planted on the target.
</Callout>

## Getting reachable

Spin the container up and load `http://localhost:8080/install.php`. Click the
link to install bWAPP, which creates the MySQL database, then log in with bee
and bug. Pick a bug from the menu, set its security level to low, and work the
objectives below. Use the hints if you stall; each one costs a few points, so
try on your own first.
