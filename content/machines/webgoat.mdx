## About this target

WebGoat is OWASP's teaching application. Unlike a free-for-all target, it walks
you through one vulnerability class at a time with instructions, a live form, and
a server-side check that only passes when you genuinely exploit the bug. It is a
step up from the trivial boxes because the lessons demand you actually land the
attack, not just recognize it.

Your two objectives here: **clear an injection lesson** (user), then **clear an
access control lesson** (root).

<Callout type="security" title="Authorized target only">
You are running this container on your own machine. That is the only reason it
is legal to attack it. Never point these techniques at an application you do not
own or have written permission to test.
</Callout>

<Callout type="info" title="How flags work on Phase A machines">
Docker and bring-your-own-VM boxes use proof tokens revealed through the hints
once you have genuinely completed the objective. Capture a flag by doing the
work, then submitting the token. Phase B hosted machines will issue real
per-instance flags planted on the target.
</Callout>

## Getting reachable

Spin the container up and load `http://localhost:8080/WebGoat`. Register a local
account, log in, then work the objectives below. The lessons check your work
server-side, so a token is only fair once the lesson itself shows success. Use
the hints if you stall; each one costs a few points, so try on your own first.
