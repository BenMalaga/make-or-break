## About this target

DVWA is a small PHP and MySQL application whose entire purpose is to be broken
on purpose. What makes it a great first web box is the security selector: you can
dial each vulnerability from Low to Impossible and watch how filters change the
attack. Start on Low, learn the raw bug, then climb.

Your two objectives here: **pull data out of the database through SQL injection**
(user), then **make the server run a command you supply** (root).

<Callout type="security" title="Authorized target only">
You are running this container on your own machine. That is the only reason it
is legal to attack it. Never point these techniques at an application you do not
own or have written permission to test.
</Callout>

<Callout type="info" title="How flags work on Phase A machines">
Docker and bring-your-own-VM boxes use proof tokens revealed through the hints
once you have genuinely completed the objective. Capture a flag by doing the
work, then submitting the token. Phase B hosted machines will issue real
per-instance flags planted on the target.
</Callout>

## Getting reachable

Spin the container up and load `http://localhost:8080`. Log in with admin and
password, then open the Setup page and create the database before anything else.
Set the security level to Low, then work the objectives below. Use the hints if
you stall; each one costs a few points, so try on your own first.
